# Roteiro para apresentação no portfólio

## Screenshots recomendados

Quando a release final estiver pronta, capture imagens reais do projeto em execução e salve em `docs/images/`:

1. Home — hero e proposta do produto.
2. Serviços — cards e ação de reserva.
3. Profissionais — perfis, especialidades e avaliações.
4. Fluxo de reserva — escolha de data/horário.
5. Minha agenda — visão do profissional.
6. Dashboard administrativo — indicadores e gráficos.
7. Swagger — endpoints da API REST.
8. GitHub Actions — pipeline aprovado.
9. Test Explorer — suíte de testes aprovada.

## Demonstração curta

Uma apresentação de 60–90 segundos pode seguir: Home → serviço → profissional → reserva → agenda profissional → dashboard → Swagger → testes/CI.

## Pontos técnicos para destacar

- ASP.NET Core MVC + Web API no mesmo domínio de negócio.
- EF Core e SQL Server.
- Identity, roles e JWT.
- Regras de disponibilidade e conflito de agenda.
- DTOs, Services, Repositories, AutoMapper e FluentValidation.
- Testes automatizados.
- Docker Compose.
- CI com GitHub Actions.
